| Endpoint                                                   | Description                              |
| ---------------------------------------------------------- | ---------------------------------------- |
| `GET /api/v1/admin/analytics/notifications/summary`        | Total notifications by status            |

| `GET /api/v1/admin/analytics/parcels/total`                | Total parcels handled                    |
